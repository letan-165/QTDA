## Ghi chú
> ⚠️ Thông tin cấu hình các host chi tiết trong file `.env`.

> ⚠️ Nếu chạy `mặc đinh` cần cấu hình giống trong file:  `src/main/resources/application.yml`

> ⚠️ Nếu chạy với `.env` cần cài extension **EnvFile** hoặc nhập thủ công từ `.env` đến file: `src/main/resources/application.yml`
